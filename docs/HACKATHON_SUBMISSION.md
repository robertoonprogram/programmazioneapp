# Hackathon submission guide

## Repository

**https://github.com/robertoonprogram/programmazioneapp**

The repository is the source reference for the LiberaPack demonstration, reference calculation engine, tests and documentation. It does **not** currently include a complete export of the externally hosted Evolus workspace.

## Suggested walkthrough

1. Introduce the warehouse problem: separate orders lead to repeated picking and unnecessary packaging.
2. Show the three principal areas: **Orders**, **Products** and **Boxes**.
3. Open a sample order, inspect available products and box formats and run packing.
4. Show the aggregated picking list and the separation between customers' parcels.
5. Explain Larry's AI responsibilities on Evolus (explanations, anomaly detection, operator support).
6. Describe optional Shopify or other commerce connections.
7. State what is live versus simulated, and show test evidence.

## Evidence to attach when available

- Public repository link (above).
- Executable demonstration or screen recording.
- UI screenshots of order flow and calculated output.
- Exported Evolus agent/workflow design and execution evidence.
- Real API-call evidence with secrets redacted.
- AMD deployment/model evidence appropriate to the event's actual criteria.
- Description of tested limitations and future roadmap.

A GitHub source repository alone does **not** certify event eligibility or confirm all platform requirements. Validate the form fields and technical rules at submission time.

## Short product description

> LiberaPack is a warehouse packing and order-preparation assistant. It centralizes orders, products and box formats, calculates deterministic packaging proposals, and generates consolidated picking information. Larry, its Evolus-based AI agent, is designed to explain decisions and flag anomalies. The architecture can integrate with Shopify and other e-commerce systems.

## Accuracy notes

Do not describe demo products as real customers, simulations as production transactions, or planned Evolus/AMD configuration as successfully connected unless the relevant evidence has been collected.
