# Short presentation script (English)

**Live speaking draft**

> Larry is our AI warehouse agent, and LiberaPack is the system it supports. The platform has three main sections: Orders, Products and Boxes. Orders show what customers purchased. Products store item details, such as size and weight. Boxes define available packaging. LiberaPack calculates packing proposals and organizes picking, so warehouse teams can collect products efficiently. Larry can explain results and flag anomalies. We designed the platform to connect to Shopify or other stores, allowing incoming orders and product information to be handled automatically when an integration is configured.

## Demonstration order

Show the interface first, then the order list, the product catalog, and the box settings. Run one sample packing calculation. Explain the consolidated picking view. End with Larry and the possible Shopify connection.

## Recording notes

The video should distinguish demonstration data from authenticated real orders. Avoid showing API tokens or customer records. If live integrations are unavailable, describe them as integration capabilities or planned connections, not as successfully installed services.
