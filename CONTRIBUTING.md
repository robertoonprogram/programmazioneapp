# Contributing to LiberaPack

LiberaPack is an evaluation-stage project. **This repository is not published under an open-source license.** See [NOTICE.md](NOTICE.md).

## Source and authorship hygiene

- Explain the purpose of a change and reference any relevant issue or design decision.
- Identify third-party code, assets, libraries or external reference material, including their source and terms.
- Do not contribute proprietary company source, vendor Delphi/OS1 source, production credentials or real customer data unless explicit rights and permissions have been established.
- Mark code that has not yet been tested on live Evolus/Shopify/AMD infrastructure as unverified.
- Preserve original commit history; avoid force pushes and altering earlier commit dates.
- AI-assisted changes are permitted where appropriate but must be reviewed and not presented as independent original human authorship without basis.

Submitting a pull request does not itself transfer intellectual property rights to the repository maintainer. Obtain an explicit contribution agreement before introducing material where reuse/distribution rights are unclear.
